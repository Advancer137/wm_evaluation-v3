你会看到同一初始场景下的两段视频。请对每段视频依次判断：视频是否有效、是否完成基础任务、主体与场景是否保持一致，再判断是否呈现偏好 A、偏好 B。

◎
只看可见证据

不要根据文字补全未展示的动作。两段视频可以都满足、都不满足，或无法判断。X/Y 与生成条件的对应关系已隐藏。

01 / 开始前看几个例子示意情境，不是真实评测视频
例 01

明确可见

偏好 A：停在停止线前。视频清楚显示车辆停车。

A → 是　 B → 否
例 02

不要强行二选一

两段视频都停在路口，且都没有驶过。两段视频对“驶过路口”都应判断为否。

X 和 Y 可以同为“否”
例 03

证据不足

车辆驶近路口后视频结束，看不到是否停车或驶过。

选择“无法判断”
例 04

动作做反或时间倒流

基础任务是“把烤盘放进烤箱”，视频里却是把烤盘从烤箱里拿出来；或车辆在倒退；或画面基本静止。视频能正常播放，仍选“有效”。

基础任务 → 未完成；偏好不再询问，按“否”记录
例 05

只完成了一部分

基础任务是“跑向软垫并跳上去”，视频里只有奔跑、没有起跳；或石蛇只缠绕、没有压碎遗迹。方向和主体是对的，只缺后半或结果。

基础任务 → 部分完成；偏好仍要回答，只依据已出现的画面判断
例 06

画面瑕疵不影响答案

加油的视频里有一瞬间人与加油机重合，或缺少取下油枪的过程，但加油这件事清楚可见、油枪的快慢也看得清。不要因为画面不自然就改答案。

基础任务 → 完成；偏好照常判断
例 07

能看清，但没做到

基础任务完成了，但偏好 A（在停止线前停下）并没有出现，车辆直接驶过。清楚地没有做到，要选“否”，不是“无法判断”。

A → 否（不是“无法判断”）
